## Soru
[DAKTİLO] 87- sim h: hiperkalemi laboratuar bulgulari ve ekg de görülen değişiklikler
## Cevap
[DAKTİLO] Hiperkalemi Nedenleri
[SLAYT] Hiperkalemi nedenleri (akış şeması): Psödohiperkalemi → Ölçüm hatası ; Hemoliz ; Lökositoz ; Trombositoz ; Turnikenin fazla sıkılması. Hücre dışına çıkışta artma → Egzersiz ; Rabdomiyoliz ; Crush sendromu ; Tümör lizis ; Doku nekrozu ; Hiperkalemik periyodik paralizi. Hücre içine girişte azalma → İnsülin eksikliği ; Aldesteron eksikliği ; Beta bloker ; Asidoz. Renal klirensin azalması → ABY ; KBY ; İlaçlar ; K tutucu diüretikler ; NSAID ; Heparin ; ACEI/ARB ; Beta bloker ; Digoksin ; Psödohipoaldosteronizm
[SLAYT] HİPERKALEMİ — Serum K değerinin 5.5 meq/lt'nin üzerinde olmasıdır. · En yaygın nedeni hemolizdir. · Ventriküler fibrilasyon,tam kalp bloğu, asistoli gibi ritimlere neden olabilir. · Diğer bulgular; -nöromuskuler disfonksiyon -parestezi -arefleksi -yükselen paralizi -gastrointestinal(bulantı,kusma,ishal)
[SLAYT] EKG Bulguları (Ortaya çıkma sırasına göre): -Uzun, sivri T dalgası (>10 mm) ve kısalan QT aralığı -P dalgası kaybı -QRS genişlemesi -Ventriküler fibrilasyon -Kardiyak arrest

## Cevap
[SLAYT] (tarama) KANAMA DİYATEZİ: Hemostaz basamaklarındaki bozukluk sonrası ortaya çıkan klinik tablo. Kanama diyatezi olan hastalarda sık gördüğümüz durumlar: (tablo, 4 sütun) ✓ Peteşi ✓ Purpura ✓ Ekimoz ✓ Epistaksis | ✓ Diş eti kanaması ✓ Hemartroz ✓ Hematüri ✓ Hemoptizi | ✓ Hematemez ✓ Melena ✓ Hematokezya ✓ İntrakranial kanama | ✓ Retroperitoneal kanama ✓ İntrabdominal kanama ✓ Cerrahi müdahele sonrası kanama ✓ Menoraji. Kanama diyatezi olan hastaya yaklaşım: 1. Öykü - Aile öyküsü: • Kanamanın varlığı –şiddeti, Kanamanın yeri-süresi, Kanamayı hızlandıran-yavaşlatan nedenler • İlaçlar Aspirin, NSAİD, Beta laktam türü antibiyotikler, antiagregan, antikoagülan • Yakındığı yer dışında kanama var mı? (DIC, ITP) • Kanama dışında başka semptomu var mı? (Kanser, Siroz, Gebelik, SLE, Üremi) • Aile öyküsü (göbek kordonu kesildikten sonra durup tekrar başlayan kanama (FXIII eksikliği) • Sünnet sonrası kanama • Hastanede uzun süre yatmış, ağızdan besin alamayan, çeşitli antibiyotikler kullanan malnutrisyonlu hasta K vitamini eksikliği. 2. Fizik Muayene • Vital bulgular • Peteşi, purpura, ekimoz • Mukokütanöz kanama • Hemartroz eklem muayenesi • Retroperitoneal kanama • Palpabl purpura varlığı • Sistem muayenesi mutlaka yapılmalı!! ☆ Damar duvarı hasarı ya da trombosit sayı veya fonksiyon bozukluklarında mukokütanöz kanamalar görülür. Primer hemostaz ile ilişkilidir. ☆ Faktör eksikliğinde gördüğümüz kanamalar daha ciddi kanamalardır. Derin doku kanamaları ve eklem içi kanamalar oluşur. Kanama kontrolü sağlandıktan sonra tekrar kanamaya başlar. Sekonder hemostaz ile ilişkilidir.
[SLAYT] (tarama, devam) Kalıtsal Kanama Bozuklukları: Primer hemostazla ilişkili → Trombosit fonksiyon bozuklukları, vWF hastalığı ; Sekonder hemostazla ilişkili → Faktör eksiklikleri, Hemofililer (en sık Faktör VIII eksikliği görülür). Edinsel Kanama Bozuklukları: • Immun trombositopenik purpura (ITP) • Trombotik trombositopenik purpura (TTP) • Yaygın damar içi pıhtılaşma sendromu (DIC) • Karaciğer Hastalıkları • Heparin ile ilişkili trombositopeni.

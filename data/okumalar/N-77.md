## Soru
[DAKTİLO] 77- Şule hoca:Hiponatremi ile gelen hastada idrar osmolaritesine bakarsın.sonra ne bakarsın?
## Cevap
[DAKTİLO] Ekstravaskuler volüm.
[SLAYT] (görüntü içinde el yazısı akış şeması) HİPONATREMİ şeması:
Plazma Osmolalitesi = (Na x 2) + (Glukoz / 18) + (BUN / 2.8)
PLAZMA OSMOLALİTESİ → dört dal:
- 280-285 → İZOTONİK HİPONATREMİ ; balon: yalancı hiponatremi, lipit ve prot. konst. artışına bağlı görülür, en tipik örneği. Aslında hiponatremi yok lipit ve prot. bağlı. ; – Hiperlipidemi ; – Hiperparaproteinemi ; – Multipl Myelom
- <285 → HİPOTONİK HİPONATREMİ → EKSTRASELÜLER SIVI VOLÜMÜ →
  - AZALMIŞ : Total vücut suyu ↓ ; Total vücut Na'sı ↓↓ → HİPOVOLEMİK HİPONATREMİ (balon: Hipovolemiyi gösteren en önemli bulgu: ORTOSTATİK HİPOTANSİYON ; balon: Hipovolemik hiponatreminin en sık sebebi Diüretik kull. Vücutta en çok Na kaybı yaptıran diüretik → furosemid ; Hiponatremiye en sık yol açan ↳ tiyazid) → İDRAR OSMOLARİTESİ / İDRAR SODYUMU →
    - İdrar Osm >100 mosm/kgH2O ; İdrar Na <20 mmol/L → BÖBREK DIŞI KAYIP: – Kusma, nazogastrik drenaj ; – Diyare, peritonit ; – Aşırı Terleme ; – Üçüncü boşluklara kayıp ; – Yanık ; – Pankreatit ; – Travma ; – Rabdomiyoliz
    - İdrar Osm >100 mosm/kgH2O ; İdrar Na >20 mmol/L → BÖBREKTEN KAYIP: – Diüretikler (furosemid) (en sık) ; – Tuz kaybettiren nefropati ; – Mineralokortikoid eksikliği ; – Osmotik diürez ; – Bikarbonatüri ; – Ketonüri ; – Serebral tuz kaybı sendromu.
  - NORMAL : Total vücut suyu ↑ ; Total vücut Na ↔ → NORMOVOLEMİK HİPONATREMİ → İDRAR OSMOLARİTESİ / İDRAR NA'SI →
    - İdrar Osm >100 mosm/kgH2O ; İdrar Na >20 mmol/L → – Uygunsuz antidiürez send. (SIADH) ; – Hipotiroidizm ; – Glukokortikoid eksikliği ; – Nefrojenik uygunsuz antidiürez sendromu
    - İdrar osmolaritesi <100 mosm/kgH2O ; İdrar Na'sı <20 mmol/L → – Primer polidipsi ; – Düşük solüt alımı ; – Egzersiz ; – Cerrahi girişim ; – Reset osmostat
  - ARTMIŞ : Total vücut suyu ↑↑ ; Total vücut Na ↑ → HİPERVOLEMİK HİPONATREMİ → İDRAR OSMOLARİTESİ / İDRAR SODYUMU →
    - İdrar Osm >100 mosm/kgH2O ; İdrar Na <20 mmol/L → – Kalp yet. ; – Siroz ; – Nefrotik Send.
    - İdrar Osm >100 mosm/kgH2O ; İdrar Na >20 mmol/L → – ABH ; – KBY
- >285 → HİPERTONİK HİPONATREMİ : – Hiperglisemi ; – Mannitol infüzyonu ; – Gliserol tedavisi ; – Radyokontrast ilaçlar ; balon: Etkin osmotik solütler – mannitol – glikoz … ; balon: Normalde hiponatremide osmolalitenin düşmesini beklerz, osmolalitenin yüksek olmasının tek açıklaması Na dışında etkin osmotik solüt yüksekliği. En sık sebebi hiperglisemi, hc. dışı glukoz artışına bağlı gradient farkıyla su hc.'lerden dışarı çıkar, hipertonik durum oluşur.

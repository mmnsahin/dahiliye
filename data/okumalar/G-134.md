[DAKTİLO] Serolojik bulgular
[SLAYT] Serolojik test — Spesifite: Anti deaminated gliadin IgA %95 ; Anti endomysium IgA 95 ; Anti doku transglutaminaz IgA 95 ; Anti gliadin IgA <85. Yeni çıkanlar: Anti-neo-epitope tTg >95 ; Anti-neo-epitope mTg >95
[SLAYT] Serolojik testler (doku transglutaminaz için): Yanlış pozitiflik: İBH, PBC, Tip I DM ; SLE, RA, Wegener ; Pemfigus, Psöriyazis ; Good-pasture send ; Konnektif doku hst ; Vaskulitler ; Neoplastik has lar ; Son dönem KY ; Serebral palsi, Down send ; EBV inf takiben ; Geçici de olabilir. Yanlış negatiflik: Yaşlılık ; IgA eksikliği ; İmmün yetmezlik ; İnce barsakta aşırı bakteri çoğalması ; Refrakter çölyak ; Viral infeksiyonlar ; Glutensiz diyet ; Geçici olabilir
[DAKTİLO] Endoskopik/histopatolojik bulgular
[SLAYT] • Endoskopi: – 2 adet bulbustan – 4 adet duodenum ikinci kısmından – Kıvrımlarda taraklanma – Kıvrımlarda düzleşme. • Histopatolojik bulgular: – Marsh 0: Normal – Marsh I: IEL>25/100 enterosit – Marsh II: IEL>25+kript hiperplazisi – Marsh IIIa: IEL>25+kript hiperplazisi + parsiyel villöz atrofi – Marsh IIIb: IEL>25+kript hiperplazisi + subtotal villöz atrofi – Marsh IIIc: IEL>25+kript hiperplazisi + total villöz atrofi
[SLAYT] • Tedavi: – Glutensiz diyet. • Geliştirilmekte olan tedaviler: – Endopeptidazlar (Latiglutenaz) – Sıkı bileşke düzenleyiciler (Larazotid) – tTG inhibitörleri – İmmünmodulasyon – Interleukin-15 antagonistleri – Probiyotikler – Montelukast (leukotrien reseptör antagonisti)
[SLAYT] (akış şeması) Çölyak düşünülen hasta → Anti tTG IgA+serum IgA → (a) IgA Eksikliği → Anti tTG IgG → Negatif → Diğer hstlar ; Pozitif → Biyopsi. (b) Seroloji +, IgA:N → Biyopsi. (c) Seroloji (-). IgA:N → Çölyak şühesi devam ediyor mu? → Evet → Biyopsi ; Hayır → Diğer hst lar

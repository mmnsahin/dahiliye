## Soru
[DAKTİLO] 100- hiponatremili hastaya yaklaşım çeşitleri etyolojisi
## Cevap
[SLAYT] PLAZMA OZMOLALİTESİ (Na x 2) + (Glukoz/18) + (BUN/2.8)
[DAKTİLO] Öncelikle plazma ozmolalitesine bakılır.
[SLAYT] Hiponatremiye tanısal yaklaşım: HİPONATREMİ → PLAZMA OSMOLALİTESİ (256 mOsm/kg [?]) → 280-285 İZOTONİK HİPONATREMİ (Hiperlipidemi ; Hiperparaproteinemi) ; <280 HİPOTONİK HİPONATREMİ (Ekstrasellüler sıvı volümü) ; >285 HİPERTONİK HİPONATREMİ (Hiperglisemi ; Mannitol infüzyonu ; Gliserol tedavisi ; Radyokontrast ajanlar)
[SLAYT] Hipotonik hiponatremiye tanısal yaklaşım: EKSTRASELLÜLER SIVI VOLÜMÜ → AZALMIŞ (Total vücut suyu ↓, Total vücut Na ↓↓ → HİPOVOLEMİK HİPONATREMİ) ; NORMAL (Total vücut suyu ↑, Total vücut Na ↔ → NORMOVOLEMİK HİPONATREMİ) ; ARTMIŞ (Total vücut suyu ↑↑, Total vücut Na ↑ → HİPERVOLEMİK HİPONATREMİ)
[DAKTİLO] Hipervolemi yokluğunda idrar sodyumunun <20 olması böbrek dışı kayıpları gösterir. Hipovolemik hiponatremi için altın standart izotonik infüzyonundan sonra hiponatreminin düzelmesidir.
[SLAYT] Hipovolemik hiponatremiye tanısal yaklaşım: İDRAR SODYUMU / İDRAR OSMOLALİTESİ → İdrar Na <20 mmol/L, İdrar osmolalitesi >100 mOsm/kg H2O → BÖBREK DIŞI KAYIP: Kusma, nazogastrik drenaj ; Diyare ; Aşırı terleme ; Üçüncü boşluklara kayıp ; Yanık ; Pankreatit ; Travma — İdrar Na >20 mmol/L, İdrar osmolalitesi >100 mOsm/kg H2O → BÖBREKTEN KAYIP: Diüretikler ; Tuz kaybettiren nefropati ; Mineralokortikoid eksikliği ; Ozmotik diürez ; Bikarbonatüri ; Ketonüri ; Serebral tuz kaybı sendromu
[SLAYT] Hipervolemik hiponatremiye tanısal yaklaşım: İDRAR SODYUMU / İDRAR OSMOLALİTESİ → İdrar Na <20 mmol/L, İdrar osmolalitesi >100 mOsm/kg H2O → Kalp yetmezliği ; Siroz ; Nefrotik sendrom — İdrar Na >20 mmol/L, İdrar osmolalitesi >100 mOsm/kg H2O → Akut böbrek hasarı ; Kronik böbrek yetmezliği
[SLAYT] Normovolemik hiponatremiye tanısal yaklaşım: İDRAR OSMOLALİTESİ / İDRAR SODYUMU → İdrar osmolalitesi >100 mOsm/kg H2O, İdrar Na >20 mmol/L → Uygunsuz antidiürez sendromu (SIADH) ; Hipotiroidizm ; Glukokortikoid eksikliği ; Nefrojenik uygunsuz antidiürez sendromu — İdrar osmolalitesi <100 mOsm/kg H2O, İdrar Na <20 mmol/L → Primer polidipsi ; Düşük solüt alımı ; Egzersiz ; Cerrahi girişim ; Reset osmostat

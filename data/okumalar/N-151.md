## Soru
[DAKTİLO] 151- Sim Kutlayan: periton ve hemodiyaliz avantajları dezavantajları birbirine üstünlükleri
## Cevap
[SLAYT] Diyaliz Modalitesinin Tercihi Avantajlar/ Dezavantajlar: • Tedavi hasta özelinde , medikal ve sosyal endikasyonlar gözden geçirilerek, hasta ve hasta yakınlarının süreç hakkında bilgilendirilmesi sonrası hekimin önerisi ve hastanın son kararı ile verilmelidir.
Periton diyalizi — Avantajları: Damar giriş yolu gerekmemesi ; Antikoagülan tedavi gerekmemesi (altı çizili) ; İyi anemi kontrolü ; Daha az kan kaybı ; Hemodinamik tolerasyon daha iyi (altı çizili) ; Akut komplikasyon daha az ; İyi kan basıncı kontrolü ; Hepatit riski az ; Büyük solüt klirensi iyi ; Daha sabit biyokimya değerleri ; RRF korunması ; Merkeze bağlı kalmama, otonomi (altı çizili) ; Düşük maliyet
Periton diyalizi — Dezavantajları: Küçük solüt klirensi az ; Peritonit riski ; Obezite eğilimi ; Kan şekeri kontrolünün güçlüğü ; Malnutrisyon ; Hipertrigliseridemi ; Herni ; Yardıma ihtiyaç duyma ; Hasta uyumu önemli ; Uyku sorunları (aletli PD) ; Enkapsüle peritoneal skleroz riski
Hemodiyaliz — Avantajları: Saat başına yüksek etkinlik ; Küçük solüt klirensi yüksek ; Tıbbi personel gözetimi ; Merkez tedavisinde sosyalleşme? ; Daha az malnutrisyon
Hemodiyaliz — Dezavantajları: Damar giriş yolu sorunları ; Antikoagülan kullanımı ; Kan kayıpları ; İşlem sırasında hipotansiyon, kramp ; Hepatit bulaş riski ; Merkeze bağlı kalma

## Soru
[DAKTİLO] Gastroenteroloji^ pankreatitte ranson kriterleri
## Cevap
[SLAYT] Ranson prognostik kriterleri — Başvuruda: 1. Yaş >55 y ; 2. Lökosit >16.000 mm³ ; 3. Kan şekeri >200 mg/dl ; 4. LDH >350 IU/L ; 5. SGOT (AST) >250 U/L. 48 saat sonra: 1. Htc düşmesi >%10 ; 2. BUN artışı >5 mg/dl ; 3. Serum Ca <8 mg/dl ; 4. Arteriyel pO2 <60 mmHg ; 5. Baz açığı >4 mEq/L ; 6. Tahmini sıvı sekestrasyonu >6 L. 0-2 hafif, 3-5 orta, 6-11 ciddi derecede pankreatiti gösterir

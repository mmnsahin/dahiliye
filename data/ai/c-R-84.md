### RA'nın eklem dışı bulguları
Seropozitif, uzun süreli, ağır RA'da sık; kötü prognoz göstergesi.

| Sistem | Bulgular |
|---|---|
| **Deri** | **Romatoid nodüller** (ekstansör yüzler, dirsek; RF+), romatoid vaskülit (tırnak çevresi infarkt), pyoderma gangrenosum |
| **Akciğer** | **İnterstisyel akciğer hastalığı**, plörezi/plevral effüzyon (glukoz çok düşük, eksuda), Caplan sendromu (pnömokonyoz + RA nodülleri), bronşiolit, MTX pnömonisi |
| **Kalp** | Perikardit, miyokardit, hızlanmış ateroskleroz/KAH (en önemli ölüm nedeni), kapak lezyonu |
| **Göz** | Keratokonjunktivit sikka (sekonder Sjögren), episklerit, **sklerit**, skleromalazi |
| **Hematolojik** | Kronik hastalık anemisi, **Felty sendromu** (RA + splenomegali + nötropeni), trombositoz, LGL lösemisi |
| **Sinir** | Mononöritis multipleks (vaskülit), karpal tünel sendromu, servikal miyelopati |
| **Böbrek** | Amiloidoz, ilaç (NSAİİ, altın, penisilamin, siklosporin) nefropatisi; nadiren GN |
| **Kemik** | Osteoporoz |
| **Diğer** | Sjögren, vaskülit, lenfadenopati, lenfoma riski |

### Hasta: RA + NSAİİ 20 yıl, KBY
NSAİİ'ye bağlı **kronik analjezik nefropati / hemodinamik ABH**, amiloidoz; **metotreksat** böbrek atılımlı → GFR düşünce toksik (stomatit, sitopeni, bulantı); bu hastada MTX kesilmiş, bulantı yan etkisi ya da KBH nedeniyle olabilir. İlaç dozu GFR'ye göre ayarlanır.

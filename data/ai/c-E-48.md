### Otoimmün poliglandüler sendromlar (APS / PGA)
Birden fazla endokrin bezin (ve nonendokrin organ) otoimmün yıkımı.

| | **APS-1 (APECED)** | **APS-2 (Schmidt)** | **APS-3** | **APS-4** |
|---|---|---|---|---|
| Kalıtım | **Otozomal resesif** (AIRE geni, kromozom 21) | Poligenik (HLA-DR3/DR4) | | |
| Başlangıç | **Çocukluk** | **Erişkin (20-40)**, kadın | | |
| Ana bileşenler | **Kronik mukokutanöz kandidiyazis + hipoparatiroidi + Addison** (en az 2 /3) | **Addison + otoimmün tiroid hastalığı ± Tip 1 DM** | Otoimmün tiroid + DM1 (Addison **yok**) | Diğer kombinasyonlar |
| Diğer | Alopesi, vitiligo, pernisiyöz anemi, malabsorpsiyon, hepatit, ovaryan yetmezlik, enamel hipoplazisi | Vitiligo, çölyak, pernisiyöz anemi, hipogonadizm, myasthenia | Vitiligo, alopesi, pernisiyöz anemi | |

### Tanı/yaklaşım
Otoantikorlar (anti-21-OH, anti-TPO, anti-GAD, anti-adacık, anti-parietal), hormon testleri; **bir bileşen varsa diğerlerini tara**; aile taraması. **Önce adrenal yetmezliği tedavi et**, sonra tiroid hormonu.

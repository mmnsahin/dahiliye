### Böbrek hasarı yapan romatolojik hastalıklar
| Hastalık | Böbrek tutulumu |
|---|---|
| **SLE** | **Lupus nefriti** (sınıf I-VI; en sık sınıf III-IV proliferatif ve V membranöz); proteinüri, hematüri, nefrotik/nefritik sendrom, kreatinin ↑, C3-C4 ↓ |
| **ANCA vaskülitleri** (GPA, MPA, EGPA) | Pauci-immün nekrotizan kresentik GN, RPGN |
| **Poliarteritis nodoza** | Renal arter dalları: infarkt, anevrizma, HT |
| **Anti-GBM** | Lineer IgG; RPGN ± pulmoner kanama |
| **Henoch-Schönlein (IgA vasküliti)** | IgA nefriti |
| **Skleroderma** | **Skleroderma renal krizi**: ani HT, ABH, mikroanjiyopatik hemoliz; ACE-i ile tedavi |
| **RA** | Amiloidoz, ilaç nefropatisi (NSAİİ, altın, penisilamin), nadiren GN |
| **Sjögren** | Tübülointerstisyel nefrit, RTA |
| **Behçet** | Amiloidoz, GN (nadir), renal arter anevrizması |
| **FMF** | AA amiloidoz |
| **Spondiloartropatiler** (AS, PsA) | AA amiloidoz, IgA nefropatisi, NSAİİ nefropatisi |
| **Gut** | Ürat nefropatisi, nefrolitiazis, KBH |
| **Antifosfolipid sendromu** | Trombotik mikroanjiyopati, renal ven/arter trombozu |
| **Sarkoidoz** | Granülomatöz interstisyel nefrit, hiperkalsemi |
| **IgG4 ilişkili hastalık** | Tübülointerstisyel nefrit |
| **Dermatomiyozit/polimiyozit** | Rabdomiyoliz → ATN (miyoglobinüri) |
| **Kriyoglobulinemi** | MPGN |
| **Takayasu** | Renal arter stenozu |

### Ortak yaklaşım
Her hastada **idrar tetkiki (protein, sediment), kreatinin/eGFR**; romatolojik ilaçların (NSAİİ, siklosporin, metotreksat, altın, penisilamin) böbrek yan etkileri. Şüphede biyopsi.

### Sekonder (endokrin) diyabet nedenleri
Karşı-regülatuvar (insülin antagonisti) hormonların fazlalığı → insülin direnci veya sekresyon baskılanması.

| Endokrinopati | Mekanizma |
|---|---|
| **Akromegali** (GH ↑) | İnsülin direnci, hepatik glukoz üretimi ↑ |
| **Cushing sendromu** (kortizol ↑) | Glukoneogenez ↑, insülin direnci |
| **Feokromositoma** (katekolamin) | Glukoz üretimi ↑, insülin salgısı ↓ (α2) |
| **Glukagonoma** | Glukagon fazlalığı; nekrolitik migratuvar eritem |
| **Somatostatinoma** | İnsülin, glukagon, GH baskılanması |
| **Hipertiroidi** | Glukoz emilimi ↑, glikojenoliz, insülin klirensi ↑ |
| **Primer hiperaldosteronizm** (hipokalemi → insülin salgısı ↓) | |
| **Hiperparatiroidi** (nadir) | |
| **Glukokortikoid ilaç** (iyatrojenik) | En sık endokrin neden |
| Diğer: **hemokromatoz** (pankreas demir birikimi, bronz diyabet), kistik fibroz, pankreatit/pankreatektomi, pankreas kanseri | |

### Tanı ve yaklaşım
Altta yatan endokrinopati tedavisi ile DM düzelebilir (cerrahi, ilaç); tedavi: yaşam tarzı + OAD/insülin.

### Kanserli hastada böbrek sorunları
Kanser hastasında böbrek, hastalığın kendisi, ilaçlar ya da komplikasyonlar nedeniyle etkilenir.

| Grup | Örnekler |
|---|---|
| **Prerenal** | Dehidratasyon (kusma/ishal), hiperkalsemi, sepsis, hepatorenal, ACE-i/NSAİİ |
| **Postrenal** | Üreter/mesane/pelvik tümör bası, retroperitoneal lenfadenopati/fibrozis, radyasyon fibrozisi |
| **Tümör lizis sendromu** | Hiperürisemi, hiperfosfatemi, hiperkalemi, hipokalsemi → akut ürat nefropatisi (lenfoma, lösemi, kemoterapi sonrası) |
| **Multipl miyelom / paraproteinemi** | **Cast nefropatisi** (hafif zincir), AL amiloidoz, hafif zincir depo hastalığı, hiperkalsemi, hiperviskozite |
| **Glomerüler (paraneoplastik)** | **Membranöz nefropati** (solid tümör: akciğer, kolon, meme, mide), minimal değişiklik hastalığı (Hodgkin lenfoma), FSGS, MPGN (lenfoma, CLL), amiloidoz |
| **İlaç toksisitesi** | **Sisplatin** (proksimal tübüler hasar, Mg-K kaybı), ifosfamid (Fanconi), metotreksat (kristal), mitomisin/gemsitabin (TMA), bevacizumab (proteinüri, HT), anti-VEGF, bifosfonat, **immün kontrol noktası inhibitörleri** (interstisyel nefrit), kalsinörin inhibitörü |
| **Radyoterapi** | Radyasyon nefriti |
| **Enfeksiyon** | Sepsis ATN, kontrast nefropatisi |
| **Tümör infiltrasyonu** | Lenfomatöz böbrek tutulumu |
| **Hiperkalsemi** | Malignitenin sık komplikasyonu → nefrojenik DİT, ABH |

### "İnda kapıdan giren hastada böbrek hastalığı?" (acile gelen hasta)
Akut: prerenal ABH (dehidratasyon, hipotansiyon), ATN, obstrüksiyon, rabdomiyoliz, hiperkalemi, akut GN, intoksikasyon. Kronik: KBH alevlenmesi, diyaliz hastası komplikasyonları.

### Antihipertansifleri say
ACE inhibitörleri, ARB, kalsiyum kanal blokerleri (DHP/non-DHP), tiyazid ve tiyazid benzeri diüretikler, loop diüretikler, K tutucu diüretikler (spironolakton, eplerenon), beta blokerler, alfa blokerler (doksazosin), santral etkililer (metildopa, klonidin, moksonidin), vazodilatörler (hidralazin, minoksidil), direkt renin inhibitörü (aliskiren).

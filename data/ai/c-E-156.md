### Multipl endokrin neoplazi (MEN)
Otozomal dominant kalıtılan endokrin tümör sendromları.

| | **MEN1 (Wermer)** | **MEN2a (Sipple)** | **MEN2b** |
|---|---|---|---|
| Gen | **MEN1 (menin)** | **RET** | **RET** (M918T) |
| Paratiroid | **Hiperplazi/adenom (%90+)** → hiperkalsemi | Hiperplazi (%20-30) | Yok |
| Pankreas/GİS | **Nöroendokrin tümörler** (gastrinoma, insülinoma) | | |
| Hipofiz | **Prolaktinoma** en sık | | |
| Tiroid | | **Medüller tiroid kanseri (%100)** | **MTK (agresif, erken)** |
| Adrenal | Kortikal | **Feokromositoma (%50)** | **Feokromositoma** |
| Diğer | Karsinoid, lipom, anjiyofibrom | Kutanöz liken amiloidoz, Hirschsprung | **Mukozal nörom**, **Marfanoid habitus**, medülla sinir kalınlaşması, intestinal ganglionöromatoz |

### MEN2b’de neler görürsün?
- **Dudak/dil/göz kapağında mukozal nöromlar** (kalın, “şişkin dudaklar”)
- **Marfanoid görünüm** (uzun ince ekstremiteler, pes cavus), kalın kornea siniri
- Gastrointestinal ganglionöromatoz (konstipasyon, megakolon)
- **Çok agresif MTK** (bebeklikte), feokromositoma; **hiperparatiroidi YOK**

### Yaklaşım
- RET analizi, aile taraması; profilaktik tiroidektomi (MEN2b: ilk yıl; 2a: 5 yaş civarı/RET riskine göre)
- **Feokromositoma önce** (α-bloker) sonra tiroid cerrahisi; feo tek taraflı → adrenalektomi (bilateral %50-70)
- MEN1: parathyroidektomi, pankreas NET rezeksiyonu, hipofiz tedavisi

### Ektopik ACTH sendromu
Hipofiz dışı bir tümörün **ACTH (veya CRH)** salgılaması → ağır hiperkortizolizm (Cushing sendromunun ~%10-20’si).

### Nedenler
| Tümör | Not |
|---|---|
| **Küçük hücreli akciğer kanseri (SCLC)** (~%50) | Hızlı, ağır kortizol fazlalığı; hipokalemi |
| **Bronşiyal karsinoid** (%25) | Daha yavaş, gizli |
| **Timoma / timik karsinoid** | |
| **Pankreas nöroendokrin tümörü (adacık hücre)** | |
| **Medüller tiroid kanseri** | |
| **Feokromositoma**, nöroblastom | |
| Prostat, kolon, over, meme kanseri; GEP-NET | |
| Gizli ektopik odak (%10-15 bulunamaz) | |

### Klinik/laboratuvar
Hızlı kilo kaybı (kaşeksi, tipik Cushing görünümü az), **koyu pigmentasyon** (ACTH ↑↑), **şiddetli hipokalemi (mineralokortikoid etkisi) + metabolik alkaloz**, HT, DM, proksimal miyopati, psikoz; **ACTH çok yüksek** (> 100 pg/mL), UFC çok yüksek; **yüksek doz DST’ta baskılanmaz**.

### Tanı/tedavi
IPSS (santral gradient yok), toraks-batın BT, DOTATATE-PET; tümör rezeksiyonu; medikal: ketokonazol/metirapon/osilodrostat; bilateral adrenalektomi.

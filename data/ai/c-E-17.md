### Diyabetli hastada hedefler (ADA/TEMD)
| Parametre | Hedef |
|---|---|
| **HbA1c** | **< %7** (bireyselleştirilir: genç-sağlıklı < 6.5; yaşlı/komorbid 7.5-8.5) |
| **Açlık / preprandiyal glukoz** | 80-130 mg/dL |
| **Postprandiyal (2. saat)** | < 180 mg/dL |
| **Kan basıncı** | **< 130/80 mmHg** (tolere edilirse; ESC < 140/85 genel) |
| **LDL-kolesterol** | **< 100 mg/dL** (genel); **KV hastalık/yüksek risk < 70** (ve ≥ %50 düşüş); çok yüksek risk < 55 |
| **Trigliserid** | **< 150 mg/dL** |
| **HDL** | > 40 (erkek), > 50 (kadın) |
| **Non-HDL** | < 130 (yüksek risk < 100) |
| Albüminüri | ACR < 30 mg/g |
| Kilo | %5-10 azalma (obezite) |

### Uygulama
- **KB:** ACE-i/ARB (albüminüri varsa); diüretik, KKB ek
- **Lipid:** orta-yoğun **statin** (40 yaş üstü tüm DM), yüksek riskte yoğun statin ± ezetimib; TG > 500 → fibrat (pankreatit önlemi)
- Antiagregan: sekonder korunma ya da yüksek riskli primer
- Sigara bırakma, egzersiz.

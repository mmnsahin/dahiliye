### İzole aPTT uzaması — ameliyat öncesi yaklaşım
Elektif cerrahi (kolesistektomi) öncesi **izole aPTT ↑, PT normal, trombosit normal** → önce **neden bulunmalı**, sonra cerrahi planlanmalı.

### Nedenler
| Neden | Kanama? |
|---|---|
| **Heparin** (tedavi, kontaminasyon: heparinli hat) | Kanama olabilir |
| **Faktör VIII, IX, XI eksikliği** (hemofili A, B, C), **vWD** (VIII düşer) | **Evet** |
| **Faktör XII, prekallikrein, HMWK eksikliği** | **Hayır (kanama yok)**; tromboz riski değil |
| **Lupus antikoagülanı (APS)** | **Hayır, tromboz riski ↑** |
| **Faktör inhibitörü** (edinsel hemofili, VIII antikoru) | **Evet (ağır)** |
| Yetersiz doldurulmuş tüp, yüksek hematokrit (artefakt) | |

### Dilüsyon (mix) testi
Hasta plazması + **normal plazma 1:1** karıştırılır, aPTT tekrarlanır.
- **Düzelir** → **faktör eksikliği** (hemofili vb.)
- **Düzelmez** → **inhibitör** (lupus antikoagülanı veya faktör inhibitörü); 1-2 saat inkübasyonda uzar → **faktör inhibitörü (edinsel hemofili)**; hemen uzar → lupus antikoagülanı
- Sonra: **faktör düzeyleri** (VIII, IX, XI, XII), vWF, **Bethesda inhibitör titresi**, dRVVT/silika pıhtılaşma zamanı (LA), antikardiyolipin/β2GP1

### Ne yapılır?
1. Kanama öyküsü, aile öyküsü, ilaç (heparin)
2. **Hematoloji danışma**
3. Etiyolojiye göre: kanama riski yok (XII eksikliği, LA hafif) → cerrahi yapılabilir (LA: tromboz profilaksisi); VIII/IX eksikliği → faktör konsantresi/desmopressin; inhibitör → bypass ajan (aktive protrombin kompleks, rFVIIa), immünsüpresyon.
4. Gereksiz FFP vermemek.

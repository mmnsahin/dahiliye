### Kanserde tedavi prensipleri
**Tedavi yaklaşımı:** tanı → **evreleme (TNM)** → performans durumu (ECOG) → **amaç belirleme (küratif / adjuvan / neoadjuvan / palyatif)** → multidisipliner kurul → tedavi → izlem.

### Tedavi modaliteleri
| Modalite | Not |
|---|---|
| **Cerrahi** | Küratif rezeksiyon (lokal/lokorejyonel); tanısal biyopsi; debulking; palyatif (obstrüksiyon); koruyucu/profilaktik; metastazektomi |
| **Radyoterapi** | Lokal küratif (baş-boyun, prostat, serviks), adjuvan, palyatif (kemik metastazı, SVK sendromu, kord basısı) |
| **Kemoterapi** | Sitotoksik (alkilleyici, antimetabolit, antrasiklin, taksan, vinka, platin, topoizomeraz); yan etkiler (kemik iliği, GİS, alopesi, nöropati); küratif (lösemi, lenfoma, testis, koryokarsinom) |
| **Hormonal tedavi** | Meme (tamoksifen, aromataz inh.), prostat (ADT) |
| **Hedefe yönelik** | TKİ (imatinib, EGFR, ALK), monoklonal antikor (trastuzumab, rituksimab, bevasizumab), PARP inh. |
| **İmmünoterapi** | Kontrol noktası inhibitörleri (anti-PD-1/PD-L1, CTLA-4), CAR-T; immün ilişkili yan etkiler |
| **Kök hücre nakli, destek** | |

### Tedavi hedefleri
- **Küratif:** erken evre; lokal (cerrahi/RT) ± sistemik
- **Adjuvan:** cerrahi sonrası mikrometastaz ↓ (meme, kolon)
- **Neoadjuvan:** cerrahi öncesi tümör küçültme / organ koruma (rektum, mide, meme)
- **Palyatif:** yaşam süresi uzatma, semptom kontrolü, yaşam kalitesi

### Genel ilkeler
Tümör biyolojisi (histoloji, moleküler: ER/PR/HER2, EGFR, KRAS, MSI), hasta uygunluğu (ECOG, komorbidite, yaş), yanıt kriterleri (RECIST), toksisite yönetimi (CTCAE), destek tedavi (antiemetik, G-CSF, ağrı, beslenme), onkolojik aciller (febril nötropeni, SVK sendromu, kord basısı, hiperkalsemi, tümör lizisi), palyatif bakım ve hasta onamı.
